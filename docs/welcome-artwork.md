# Welcome Hero Artwork

`public/images/planning-horizon.webp` is decorative artwork generated with the built-in image-generation tool. It contains no user data and is bundled with the static site; the browser makes no image-service request. The generated PNG was encoded as WebP (1536 × 1024, about 140 KiB) without compositing or visual edits. CSS handles responsive cropping and fading, while copy and controls remain real HTML.

On narrow screens the image is a shallow strip below the hero copy. At a planner content width of at least 48rem, it blends into the right side. The three journey cards use restrained blue, warm ivory and lavender gradients. Data & Privacy uses `linear-gradient(135deg, #111c2f, #1f67d6)` with light blue supporting text.

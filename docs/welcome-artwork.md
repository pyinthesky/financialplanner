# Welcome Hero Photography

`public/images/quiet-harbor.webp` is the harbor photograph supplied and selected during design review. It replaces the generated landscape illustration. The original photograph is preserved; the site uses a WebP copy (1494 × 1992, about 140 KiB), with metadata omitted during encoding. It is bundled with the static site, so the browser makes no third-party image request.

CSS mirrors the photograph horizontally to put the pier on the right, and handles responsive cropping and fading. No generative edits were applied to this photograph. Copy and controls remain real HTML.

On narrow screens the image is a shallow strip below the hero copy. At a planner content width of at least 48rem, it blends into the right side. The three journey cards use restrained blue, warm ivory and lavender gradients. Data & Privacy uses `linear-gradient(135deg, #111c2f, #1f67d6)` with light blue supporting text.
